
Al-powered Image and Video Editing
Developing intelligent tools that can assist users in image and video editing tasks, such as automatic object removal, style transfer, or video stabilization.


## Style Transfer

A collection of projects that implement neural style transfer techniques using various frameworks.

- **pytorch-neural-style-transfer**  
  A PyTorch implementation of neural style transfer, allowing users to apply artistic styles to images.  
  https://github.com/gordicaleksa/pytorch-neural-style-transfer

- **Very-Fast-Neural-Style-Transfer**  
  An implementation focusing on real-time style transfer using feed-forward neural networks.  
  https://github.com/yash-choudhary/Very-Fast-Neural-Style-Transfer

- **Neural-Style-Transfer**  
  A project demonstrating neural style transfer techniques to blend content and style images.  
  https://github.com/nazianafis/Neural-Style-Transfer

- **Neural-Style-Transfer-with-Python**  
  A Python-based implementation of neural style transfer using deep learning frameworks.  
  https://github.com/mohamedamine99/Neural-Style-Transfer-with-Python

- **style-transfer**  
  A repository showcasing style transfer methods to apply artistic effects to images.  
  https://github.com/fzliu/style-transfer

- **fast-style-transfer**  
  An implementation of fast neural style transfer using TensorFlow for real-time applications.  
  https://github.com/lengstrom/fast-style-transfer

## Video Stabilizer

Repositories focused on stabilizing videos using different algorithms and approaches.

- **python_video_stab**  
  A Python tool for video stabilization using OpenCV to reduce shaky footage.  
  https://github.com/AdamSpannbauer/python_video_stab

- **selfievideostabilization**  
  A project aimed at stabilizing selfie videos by analyzing and smoothing motion.  
  https://github.com/jiy173/selfievideostabilization

- **L1Stabilizer**  
  A video stabilization method implementing L1 optimization techniques.  
  https://github.com/ishit/L1Stabilizer

- **VideoStabilizer**  
  A simple video stabilizer tool that processes input videos to reduce unwanted motion.  
  https://github.com/ryanneph/VideoStabilizer

- **Video_Stabilizer**  
  A repository providing scripts and tools for stabilizing videos using various algorithms.  
  https://github.com/EricHu214/Video_Stabilizer

## Object Removal

Projects aimed at removing objects from videos or images using automated inpainting or adversarial methods.

- **video-object-removal**  
  A project that enables the removal of objects from videos by utilizing deep learning techniques.  
  https://github.com/zllrunning/video-object-removal

- **Automated-objects-removal-inpainter**  
  Combines semantic segmentation and inpainting to automatically remove specified objects from images.  
  https://github.com/sujaykhandekar/Automated-objects-removal-inpainter

- **Deep-Object-Removal**  
  Utilizes conditional Generative Adversarial Networks (cGANs) to remove objects from photos and reconstruct the background.  
  https://github.com/VPanjeta/Deep-Object-Removal

- **adversarial-object-removal**  
  Codebase for the paper "Adversarial Scene Editing: Automatic Object Removal from Weak Supervision," implementing adversarial methods for object removal.  
  https://github.com/rakshithShetty/adversarial-object-removal
